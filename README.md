# Library Management-System
A Java based system for managing library books, members, issuing, returns, and fines using OOP concepts and a simple console menu.

10. BookReturn
11. LibraryManagementController
12. Main
13. Searchable (Interface)

How to Run the Program:
1. Install JDK and Eclipse IDE.
2. Open Eclipse.
3. Select File -> Import -> Existing Projects into Workspace.
4. Select the Library Management System project folder.
5. Open Main.java from the main package.
6. Right click and select Run As -> Java Application.
7. Use the console menu to perform library operations.
